# LogTea

منصة أدوات مجانية لمعالجة ملفات PDF والصور والمستندات — بدون تسجيل، معالجة تتم بالكامل على الخادم، والملفات تُحذف تلقائياً بعد ساعة.

## المتطلبات

- PHP 8.1+ مع امتدادات: `gd`, `zip`, `mbstring`, `dom`, `xml`
- Composer

## التشغيل محلياً

```bash
composer install
php -S localhost:8000 -t public
```

ثم افتح `http://localhost:8000`.

## النشر (استضافة حقيقية)

- وجّه **document root** الخاص باستضافتك إلى مجلد `public/` (وليس جذر المشروع).
- على Apache: ملف `public/.htaccess` يفعّل الروابط الجميلة (`/tools/merge-pdf`) تلقائياً.
- على Nginx: يلزم قاعدة مكافئة، مثال:
  ```
  location /tools/ {
      rewrite ^/tools/([a-z0-9-]+)/?$ /tool.php?slug=$1 last;
  }
  ```
- تأكد من رفع حدود `upload_max_filesize` و `post_max_size` في `php.ini` (القيمة الافتراضية المستخدمة هنا 50-55MB).

## قبل الإطلاق

- **`public/contact.php`**: بريد `support@logtea.app` هو placeholder — استبدله ببريدك الحقيقي.
- **`public/support.php`**: روابط Buy Me a Coffee و PayPal placeholders — استبدلها بروابطك الفعلية أو احذفها.

## بنية المشروع

- `public/` — web root (الصفحات، `api/process.php`، `download.php`، الأصول الثابتة)
- `src/Tools/` — كلاس معالجة لكل أداة (16 أداة)
- `src/ToolRegistry.php` — تعريف كل أداة (الاسم، الأيقونة، الامتدادات المقبولة، الخيارات)
- `src/Support/` — رفع/تنزيل آمن، تنظيف الملفات المؤقتة، فك تشفير RC4، أيقونات SVG
- `templates/` — الهيدر والفوتر وقالب الصفحة المشترك
- `storage/` — ملفات مؤقتة فقط (خارج web root، تُحذف تلقائياً)

## حدود معروفة

بعض الأدوات محدودة النطاق تقنياً لأن المنصة لا تعتمد على أي برنامج خادم خارجي (Ghostscript/LibreOffice/qpdf) — فقط مكتبات PHP نقية عبر Composer. كل أداة محدودة تعرض ملاحظة واضحة على صفحتها:

- **ضغط PDF**: تحسّن متواضع (لا يوجد ضغط صور بجودة Ghostscript).
- **PDF إلى Word / Excel / PowerPoint**: قائم على استخراج النص، يفقد التنسيق الدقيق والجداول المعقدة.
- **PowerPoint إلى PDF**: يحافظ على النصوص والصور فقط، دون تطابق بصري دقيق.
- **إزالة كلمة مرور PDF**: يدعم تشفير RC4 القياسي (40/128-bit) فقط، وليس AES الحديث.
- **PDF إلى صور**: يستخرج الصور الممسوحة ضوئياً المضمّنة فقط، لا يرسم صفحات نصية/رسومية كصورة.

تثبيت Ghostscript/qpdf على الخادم لاحقاً (اختياري) يتيح تحسين هذه الأدوات الثلاث الأخيرة دون تغيير الواجهة.
