# LogTea

موقع شركة LogTea لتصميم وتطوير المواقع (الخدمات، الأعمال، من نحن، تواصل معنا)، ومن ضمن خدماتها **أدوات ملفات مجانية** لمعالجة PDF والصور والمستندات — بدون تسجيل، معالجة تتم بالكامل على الخادم، والملفات تُحذف تلقائياً بعد ساعة.

| الصفحة | الملف |
| --- | --- |
| الرئيسية | `public/index.php` |
| من نحن | `public/about.php` |
| الخدمات | `public/services.php` |
| أعمالنا | `public/portfolio.php` |
| الأدوات المجانية (كل الأدوات) | `public/tools.php` |
| صفحة أداة واحدة (`/tools/{slug}`) | `public/tool.php` |
| تواصل معنا | `public/contact.php` |

## المتطلبات

- PHP 8.1+ مع امتدادات: `gd`, `zip`, `mbstring`, `dom`, `xml`
- Composer

## التشغيل محلياً

```bash
composer install
php -S localhost:8000 -t public
```

ثم افتح `http://localhost:8000`.

## النشر (استضافة حقيقية)

- وجّه **document root** الخاص باستضافتك إلى مجلد `public/` (وليس جذر المشروع).
- على Apache: ملف `public/.htaccess` يفعّل الروابط الجميلة (`/tools/merge-pdf`) تلقائياً.
- على Nginx: يلزم قاعدة مكافئة، مثال:
  ```
  location /tools/ {
      rewrite ^/tools/([a-z0-9-]+)/?$ /tool.php?slug=$1 last;
  }
  ```
- تأكد من رفع حدود `upload_max_filesize` و `post_max_size` في `php.ini` (القيمة الافتراضية المستخدمة هنا 50-55MB).

## قبل الإطلاق

- **`public/contact.php`**: التواصل يتم عبر بروفايلات LinkedIn لفريق العمل (المصفوفة `$team`). يمكنك إضافة المسمى الوظيفي لكل عضو في الحقل `role` ليظهر تحت الاسم.
- **الأرقام والإحصاءات** (50+ عميل، 120+ مشروع، نتائج المشاريع...) منقولة من نسخة الموقع السابقة — راجعها قبل الإطلاق في `public/index.php` و `about.php` و `portfolio.php` و `src/ProjectRegistry.php`.
- **`public/support.php`** (صفحة التبرع القديمة): لم تعد مرتبطة من القائمة أو خريطة الموقع — احذفها أو أعد ربطها حسب رغبتك.

## بنية المشروع

- `public/` — web root (الصفحات، `api/process.php`، `download.php`، الأصول الثابتة)
- `public/assets/img/work/` — صور/شعارات مشاريع معرض الأعمال
- `src/ServiceRegistry.php` — خدمات الشركة (تغذّي الرئيسية، صفحة الخدمات، الفوتر، وقائمة الخدمات في نموذج التواصل)
- `src/ProjectRegistry.php` — مشاريع معرض الأعمال (الرئيسية وصفحة أعمالنا)
- `src/Tools/` — كلاس معالجة لكل أداة (15 أداة)
- `src/ToolRegistry.php` — تعريف كل أداة (الاسم، الأيقونة، الامتدادات المقبولة، الخيارات)
- `src/ToolSeo.php` — بيانات SEO لكل أداة: عنوان الصفحة، الوصف، الكلمات المفتاحية، خطوات الاستخدام، المميزات، والأسئلة الشائعة (تظهر في الصفحة وفي البيانات المنظمة Schema.org)
- `public/assets/img/og/tools/` — صورة مشاركة (1200×630) لكل أداة تظهر عند مشاركة رابطها على واتساب وتويتر ولينكدإن. تُولَّد بالأمر `php scripts/og-images.php` (يحتاج Google Chrome لأنه يرسم النص العربي بشكل صحيح)
- `src/Support/` — رفع/تنزيل آمن، تنظيف الملفات المؤقتة، أيقونات SVG
- `templates/` — الهيدر والفوتر وقالب الصفحة المشترك، و `templates/partials/` لبطاقات المشاريع والأدوات
- `storage/` — ملفات مؤقتة فقط (خارج web root، تُحذف تلقائياً)

## إضافة أداة جديدة

1. عرّف الأداة في `src/ToolRegistry.php` وأنشئ كلاس المعالجة في `src/Tools/`.
2. أضف بيانات SEO الخاصة بها في `src/ToolSeo.php` (إن لم تُضفها تُستخدم قيم افتراضية مبنية على اسم الأداة ووصفها).
3. شغّل `php scripts/og-images.php` لتوليد صورة المشاركة الخاصة بها.

## حدود معروفة

بعض الأدوات محدودة النطاق تقنياً لأن المنصة لا تعتمد على أي برنامج خادم خارجي (Ghostscript/LibreOffice/qpdf) — فقط مكتبات PHP نقية عبر Composer. كل أداة محدودة تعرض ملاحظة واضحة على صفحتها:

- **ضغط PDF**: تحسّن متواضع (لا يوجد ضغط صور بجودة Ghostscript).
- **PDF إلى Word / Excel / PowerPoint**: قائم على استخراج النص، يفقد التنسيق الدقيق والجداول المعقدة.
- **PowerPoint إلى PDF**: يحافظ على النصوص والصور فقط، دون تطابق بصري دقيق.
- **PDF إلى صور**: يستخرج الصور الممسوحة ضوئياً المضمّنة فقط، لا يرسم صفحات نصية/رسومية كصورة.

تثبيت Ghostscript/qpdf على الخادم لاحقاً (اختياري) يتيح تحسين هذه الأدوات الأخيرة دون تغيير الواجهة.

> **ملاحظة:** أداة "إزالة كلمة مرور PDF" أُزيلت من المنصة لاعتبارات قانونية (أداة تكسر حماية ملف لا تملكه بالضرورة). "إضافة كلمة مرور" ما زالت متاحة.
